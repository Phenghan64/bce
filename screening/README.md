# ABL / AutoDock Vina 批量试筛

2026-10-21 已实际完成 **100 个不同的 NCI 示例库分子＋1 个伊马替尼对照**的批量初筛，以及前 10 个库分子和对照的三种子复筛。共调用 Vina **152 次**，程序退出均正常；两个初筛分子因未明确的环系立体化学被结果校验隔离。

这轮验证吞吐量、质量检查、候选复筛和续跑机制。NCI 库分子没有本次 ABL 靶点的活性标签，**没有测定活性富集率、AUC、命中率或真实亲和力**。

## 实测时间和配置

| 阶段 | 任务 | 墙钟时间 |
|---|---|---:|
| 配体准备 | 101 个分子的 ETKDGv3、MMFF、Meeko | 1.47 s |
| 调度比较 A | 相同 9 个分子，1 任务 × 6 线程 | 19.14 s |
| 调度比较 B | 相同 9 个分子，3 任务 × 2 线程 | 17.23 s |
| 初筛 | 101 个分子，exhaustiveness=8，1 个种子 | **124.30 s** |
| 复筛 | 前 10 名＋对照，exhaustiveness=32，3 个种子，共 33 次 | **163.25 s** |
| 计算阶段累计 | 上述阶段之和 | **325.40 s，约 5 分 25 秒** |

阶段计时不包括编写程序、寻找数据源、阶段之间的人工工作、计时器启动之前的 Python 导入、已有受体准备或先前的 OpenFold3/MSA。对接阶段包含任务调度、搜索、SDF 导出和逐姿势校验。

本轮选择 **3 个并发任务，每个 2 线程**，总 CPU 线程预算为 6。调度小样本中耗时缩短约 10%，只测了一次，不能当成所有库的最优设置。

初筛处理速率约 **2925 个输入分子/小时**，通过校验的结果约 **2867 个/小时**。这是本次特定库、盒、受体和搜索强度的实测吞吐量；100 个库分子平均只有 **19.46 个重原子、3.3 个 RDKit 可旋转键**，比伊马替尼轻得多。不能把这个速度直接用于全部是伊马替尼大小的库，也不能与之前 exhaustiveness=32 的单分子速度直接等同。

Vina 单进程峰值 RSS 的中位数约 **447 MiB**，观测到的单进程最大值约 **647 MiB**。这些来自 macOS `time -l`，并非同时运行的整组进程峰值；本轮没有测量整机峰值或交换内存曲线。Vina 使用 CPU，没有重跑 OpenFold3。

## 输入和取样方法

- 受体：已准备好的 **1IEP 实验链 A**，路径为 `results/closed-loop-1iep/reference/receptor.pdbqt`。选择该受体是因为此前三种子的实验结构对照稳定。
- 对接盒：复用同目录 `receptor.box.txt`，30 × 30 × 30 Å；刚性、无水受体。
- 软件：AutoDock Vina 1.2.7，Meeko 0.8.0，RDKit 2026.9.1。
- 库来源：本机 RDKit 附带的 `Data/NCI/first_5K.smi`，原文件副本与 SHA-256 已保存。`nci-example-*` 是该示例文件中的记录标识，不宣称其为已核实的 NSC 编号或 ABL 活性分子。
- 过滤：单组分、分子量 200–550、15–40 个重原子、≤10 个 RDKit 可旋转键、形式电荷 −1 到 +1、指定有机元素，去重并排除检测到的未指定原子立体中心。
- 本次原始过滤后有 1414 个唯一合格记录，以随机种子 **20261021** 无放回抽取 100 个。另加入此前使用的单质子化伊马替尼（+1），不从晶体姿势初始化。
- 所有配体都从 SMILES 独立生成三维结构；保留来源的质子化／互变异构状态，没有进行 pH 状态或异构体枚举。该简化适合流程试验，真实药物筛选应进一步处理化学状态。

原计划的 DUD-E 数据接口在本次访问中返回 404，因此没有使用其活性／诱饵标签。不能把这批无标签 NCI 分子当作已知阴性对照。

## 初筛、复筛与对照结果

初筛 101 个输入均完成 Vina 搜索，**99 个分子通过全部输出校验，2 个隔离**。排名只包含 99 个通过者；伊马替尼排第 **2/99**。复筛选择初筛分数最低的 10 个库分子，再额外加入伊马替尼，不使用实验 RMSD 选择候选。

| 伊马替尼对照 | 种子 | 首位分数 kcal/mol | 对实验配体的 RMSD Å |
|---|---:|---:|---:|
| 初筛，exhaustiveness=8 | 20261021 | −11.238 | **12.082** |
| 复筛，exhaustiveness=32 | 42 | −12.857 | **0.347** |
| 复筛，exhaustiveness=32 | 2026 | −12.907 | **0.477** |
| 复筛，exhaustiveness=32 | 20261021 | −12.831 | **0.343** |

RMSD 在同一受体坐标系下计算，考虑配体化学对称性，不单独旋转／平移拟合配体。**初筛高排名没有保证正确姿势；多种子复筛在这个对照上恢复了正确方向。** 不能据此保证所有新配体也会恢复正确姿势。

10 个复筛库分子中，9 个的三次首位姿势两两 RMSD 均 ≤2 Å；`nci-example-3871` 的最大差异达 **6.09 Å**。它虽然是初筛库分子中的第一名，也不能直接当成可靠命中物。复筛采用三种子首位分数的中位数汇总，伊马替尼在这 11 个复筛分子中排名第一。

9/10 仅表示姿势重复性，**不是 90% 的命中率或准确率**。这些库分子没有实验配体位置或 ABL 活性标签。

## 两个被隔离的分子和修复

`nci-example-3618` 与 `nci-example-4211` 的 Vina 退出码均为 0。输入没有明确环系立体化学，三维导出给出了具体构型；忽略立体化学时其分子连接关系相同。严格的化学身份校验将它们拦下，未纳入排名，也没有用其他分子替换以掩盖问题。

原因是原始准备阶段使用的旧式原子立体中心检测未识别这些环系情形。已将后续准备脚本改为 `Chem.FindPotentialStereo()`，并验证它能识别这两个输入。**本次原始结果仍保留这两条失败记录**，没有把修复后的另一批取样混入本次统计。实际执行的旧脚本快照保存在结果目录 `source/*-used.py`，准确输入见 `library.json`。

## 续跑和输出验证

每个对接任务保存完整命令、输入哈希、种子、线程数、搜索强度、退出码、日志、评分、PDBQT/SDF 及输出哈希。设置变化时拒绝覆盖已有实验。成功任务要求评分有限且有序、分子身份一致、坐标有限、PDBQT/SDF/评分条数一致。共 **1350 个姿势**通过校验。

完成后再次执行初筛阶段，**101 条记录全部命中缓存**，原始 PDBQT 的修改时间没有变化；99 条成功记录和两条已知失败均保留。缓存检查阶段用时约 0.024 秒，不包含 Python 导入。已记录失败默认不重复计算，只有显式 `--retry-failed` 才重试。本次验证的是完成结果的续跑，没有模拟断电或覆盖所有故障情况。

## 使用和文件

重用本次记录，检查／继续初筛：

```bash
./run.sh python screening/run.py --output-dir results/vina-screen-abl1 --stage screen
```

在新目录创建新一轮（当前过滤器已包含环系立体化学修复，新取样不保证与本次相同）：

```bash
./run.sh python screening/prepare.py results/vina-screen-abl1-new
./run.sh python screening/run.py --output-dir results/vina-screen-abl1-new
```

`run.py` 支持 `--stage tune`、`screen`、`refine` 和默认的 `all`；后续阶段依赖前序结果。该试验脚本使用固定的本项目 ABL 受体和示例库，还不是任意受体／任意输入库的通用产品。
