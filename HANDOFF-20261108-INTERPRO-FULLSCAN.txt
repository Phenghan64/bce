五、代码改动

以下后端路径均相对于 /Users/yili/Documents/ChatGPT/autodock/。

新增 marine_agent/interpro_protocol.py：
  无第三方依赖的协议校验。校验输入 ID、序列、输出版本、序列 MD5、所有 xref、无命中记录完整性和成员库身份。
  相同序列对应多个 ID 时，所有 ID 都必须在输出中保留。
  active_library_versions 仅向业务报告暴露实际启用分析的版本，避免把元数据中的可选库误写成执行范围。

新增 marine_agent/interpro_worker.py：
  Linux 异步 HTTP Worker，持久化 job/analysis，幂等提交，单工作流队列。
  执行官方 Nextflow，显式 --no-matches-api；镜像 ID 与固定 release 校验。
  保留 JSON、TSV、trace、日志、command 和 receipt。
  取消记录可以拒绝迟到提交；进程组与带 eyoson.interpro.job 标签的 Docker 容器一起清理。
  重启时旧任务标为停止，并清理本 Worker 所属容器；不把中断任务自动当作成功。
  同输入新 attempt 使用 -resume；refresh 明确关闭复用。
  相同 FASTA 不再重写，保留 mtime，使 Nextflow 文件缓存可复用。
  Nextflow 子进程环境移除 Worker token。
  支持 --cleanup-only，供 systemd ExecStopPost 使用。

新增 marine_agent/interpro_remote.py：
  业务端 full_scan 适配器；验证健康状态、release 指纹、每个产物哈希和实际执行命令。
  镜像产物保存在业务 results/protein-domains/<analysis_id>/。
  保存 manifest、attempt、输入、Worker 信息、扫描 receipt 和报告。
  发出真实进度事件；缓存复用与本次实际计算有不同字段。
  RemoteScanStopPending 表示停止尚未得到远端确认，不能提前显示已停止。

修改 marine_agent/domain_evidence.py：
  DomainRequest.method 为 lookup/full_scan，默认仍是 lookup；按方法分发并校验不同产物。

修改 marine_agent/protein_tools.py：
  在既有 annotate_protein_domains 工具上暴露 method；没有另起一套并行 Agent 工具体系。

修改 marine_agent/task_lifecycle.py：
  保存输入的完整扫描继续执行、部分结果恢复；已完成操作不重复执行。
  配置完整扫描 Worker 后，预计算未知记录的继续流程可转入 full_scan。

修改 marine_agent/restart_recovery.py：
